# Skill の共通基準

このリポジトリの Skill を作成・更新・レビューする際の基準です。

- [共通品質基準](quality.md)
- [作成・運用ガイド](workflow.md)

必須事項と推奨事項を区別します。既存 Skill も対象ですが、基準追加だけを理由に無関係な修正を一括適用しません。差分と影響を確認し、必要な改善を提案します。新規作成は [Create Skill](../skills/ateliers-skill-create/SKILL.md)、既存 Skill の変更は [Improve Skill](../skills/ateliers-skill-improve/SKILL.md) を使用します。読み手向けの手順と図は [Skill 開発ワークフロー](../docs/skill-development-workflow.md) にあり、共通運用ルールの正本はこの standards のままです。
