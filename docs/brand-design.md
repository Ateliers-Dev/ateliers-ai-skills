# Ateliers ブランドデザイン制作（ateliers-brand-design）

作成日：2026-11-07 ／ 更新日：2026-11-07（日本標準時 JST (UTC+09:00)）

## 用途

Ateliers / Atelier Yu のブランド制作で、技術記事イラスト、UI素材、キャラクターの表情・ポーズ等を検討・制作するときに使います。A（Brand / Workshop）、B（Technical / Concept）、C（Hybrid / Narrative）のライン名を扱い、ブランド資料を確認できる範囲で制作仕様や画像生成用プロンプトに反映します。

ブランド資料・参照画像は原則として外部の正本を参照します。資料やキャラクター設定が未提供・未確定の場合は、ブランド固有の詳細を推測で固定せず、確認できる条件・要確認点・暫定案を分けます。ブランドシンボルやキャラクターはすべての画像で必須ではありません。

## 依頼例

```text
$ateliers-brand-design を使って、技術記事「イベント駆動設計の基本」の図版案を作ってください。
デザインラインは B（Technical / Concept）です。ブランドガイドと参照画像はこの会話で添付します。
まずプロンプト案とサンプルボードを確認したいので、方向性の確認前に完成素材を量産しないでください。
```

キャラクター素材では、利用できる正本・参照画像と、保持する特徴、今回変更したい表情・ポーズを指定します。正式設定が決まっていない場合も、その状態をそのまま伝えてください。

## 結果の読み方

結果では、参照資料と版、制作仕様、プロンプト、確認項目、未確定事項、承認待ちの対象を確認します。サンプルボードの承認は方向性の確認です。完成候補を正式素材として採用し、正本に登録・公開する工程では、画像・版・用途・保存先を特定した別の承認が必要です。

画像生成機能が利用できない環境では、生成したふりをせず、プロンプト・制作仕様・品質確認項目を提示します。一般素材では構図・可読性・余白・出力条件、キャラクター素材では正本との特徴保持と未確定設定の非推測を重点的に確認します。

## 制約と資料管理

画像生成・編集機能や参照画像の取扱いは、利用する製品、プラン、ワークスペース設定で異なります。Skill は機能の利用可能性を保証しません。外部送信、公開リポジトリへの追加、正本への登録・上書きには個別の許可が必要です。

ブランドアセットは制作中のため、ブランド固有の詳細仕様をこの Skill に固定していません。未承認の資料・画像を公開リポジトリへ同梱しません。将来、UI 素材やキャラクターの独自基準・反復工程・テストが確立した場合は、責務と発火条件を定めた専用 Skill への分割を検討できます。
