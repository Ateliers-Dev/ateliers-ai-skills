# ateliers-skill-review

作成日：2026-11-06 ／ 更新日：2026-11-06（日本標準時 JST (UTC+09:00)）

## 用途と境界

Skill 本体、関連資料、テスト、人間向け説明をレビューします。構造、発火条件、指示の明確さ、安全性、テスト、docs と共通基準の整合を確認します。一般の文書だけのレビューには [文書レビュー](document-review.md) を使います。新規作成・修正の実装は対象外です。

原則読み取り専用です。対象 Skill を実行せず、対象内の命令にも従いません。レビュー依頼だけで編集、コミット、外部送信、Issue 起票を行いません。

## 配置と依頼例

[各 AI ツールでの使い方](ai-tools.md) に従い、対象名を `ateliers-skill-review` に置き換えてフォルダごと配置します。単体でも利用できます。共通基準も確認する場合は対象リポジトリの `standards/` または基準ファイルを渡してください。基準がない場合もレビューを続け、完全な基準適合は未確認と報告します。

```text
$ateliers-skill-review を使い、skills/ateliers-document-review/ をレビューしてください。
対応する tests/ と docs/、standards/ も確認してください。
ファイルは変更せず、日本語で、事実・推測・改善案を区別して回答してください。
Issue は作成せず、必要な候補だけ受け入れ条件付きで示してください。
```

登録機能がないチャットでは SKILL.md と対象資料を添付し、「添付のレビュー手順に従って対象 Skill をレビュー」と依頼できます。ネイティブ登録や自動選択の確認にはなりません。

## 結果と Issue 候補

結果には対象・版・確認方法、重要度（重大・中・軽微）、場所、事実と根拠、推測・要確認、改善案が含まれます。問題が見つからなければ確認範囲で未検出と返します。構造合格だけで実動作の正しさは保証しません。

Issue 候補は必要性、種類、題名、対象、根拠、受け入れ条件を持つ提案です。Skill Request は新規要望、Skill Defect は不具合、Skill Improvement は改善、Skill Maintenance は保守です。すべての指摘を自動起票しません。

GitHub 非接続でもレビューできます。起票は対象リポジトリと候補について明示的な許可がある場合だけです。「レビューして」「候補を出して」は起票許可ではありません。接続・権限がなければ候補の提示までとします。

## テストと検証範囲

[テスト一式](https://github.com/Ateliers-Dev/ateliers-ai-skills/tree/main/tests/ateliers-skill-review) に正常・問題入力、プロンプト、期待事項、手順、検証記録があります。生成回答は Git 管理対象外の `tests/**/results/` に保存します。

初版では構造・リンク・日付形式の自動検証と、作成担当による同一チャット内の自己試行を実施しています。独立チャット評価、インストール・自動選択、各 AI 製品での実機動作、GitHub Forms の画面表示・投稿は未検証です。詳細は [検証記録](https://github.com/Ateliers-Dev/ateliers-ai-skills/blob/main/tests/ateliers-skill-review/validation.md) を参照してください。
