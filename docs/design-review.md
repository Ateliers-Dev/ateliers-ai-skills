# 技術図解の独立レビュー（ateliers-design-review）

作成日：2026-11-07 ／ 更新日：2026-11-07（日本標準時 JST (UTC+09:00)）

## 用途

Ateliers / Atelier Yu の技術記事向け概念図・アーキテクチャ図を、画像の実物、制作要件、承認済みブランド資料、必要に応じて技術一次資料に照らして独立にレビューするSkillです。初版の対象は技術図解に限ります。

制作を支援する [ateliers-brand-design](brand-design.md) と異なり、制作側と別の会話・実行コンテキストで根拠を記録し、修正候補を評価します。画像の編集・生成、正式採用、登録、公開、承認は行いません。ブランドイラスト、キャラクター、UI、SNS画像の品質保証は初版対象外です。

## 依頼例

```text
$ateliers-design-review を使い、添付の技術記事用アーキテクチャ図をレビューしてください。
制作要件、承認済みブランドガイド、対象バージョンの公式技術資料も添付します。
画像の実物を確認し、技術・ブランド・視覚・要件の4領域を分けて評価してください。
P1〜P3の指摘、根拠、未検証事項、総合判定を日本語で返してください。
画像は変更・公開せず、正式採用も行わないでください。
```

初回は制作側の自己評価や結論を渡さず、画像・要件・正式資料を先に確認します。修正版では旧指摘IDごとに状態を評価し、新たな問題は別IDにします。

## 結果の読み方

結果は、確定指摘、任意の改善提案、未検証事項を分けます。画像内の位置、観察事実、影響、改善案、判断根拠を各指摘に含みます。総合判定は「確認範囲で可」「条件付き可」「修正推奨」「判定保留」のいずれかです。レビュー上の評価は正式採用の承認を意味しません。

画像を開けない場合は画像依存の評価を行いません。ブランド資料や専門資料が不足すれば、その領域を未検証とします。レビューID、画像・資料の版や識別情報、確認日時を記録し、取得できない値は推測しません。

## テストと検証状況

[テスト手順](https://github.com/Ateliers-Dev/ateliers-ai-skills/tree/main/tests/ateliers-design-review) には架空の図解画像、画像なしケース、入力、期待事項、再現手順を置きます。架空ブランドガイドはテスト専用であり、Ateliersの正式仕様ではありません。テスト画像は公開可能な自作図で、正式なブランドアセットは含みません。

静的Fixture検査は画像ファイルの形式・寸法・SHA-256・ケース対応のみを検証します。画像の意味判断やSkillの行動は検証しません。検証記録では静的検証、AI行動試験、独立レビューを区別し、未実施範囲を明記します。
