# ateliers-document-summary

> 作成日: 2026-11-24
> 更新日: 2026-11-24
> 作成者: Codex

## 用途

既存の要件、計画、設計、作業報告から、管理者・意思決定者が状況と判断事項を短時間で把握できる概要を作る Skill です。情報を減らすのではなく、読者に合わせて結論を先に示し、詳細へのリンクで必要な深さへ案内します。

Skill 本体の正本は [GitHub 上の SKILL.md](https://github.com/Ateliers-Dev/ateliers-ai-skills/blob/main/skills/ateliers-document-summary/SKILL.md) です。

## 出力の要点

概要には必要に応じて、結果・目的、現在の状況、必要な判断、主要リスク・制約、次工程、根拠となる詳細資料へのリンクを含めます。おおむね1ページを目安にしますが、項目や長さは読者の判断に必要な内容で決めます。

管理者向け概要は、実装指示、技術仕様、受入条件を置き換えません。要件と詳細設計は原本に保持し、概要から相互参照します。決定・状態・範囲・リスクに食い違いがあれば、推測で埋めず明示します。

短い資料に無理な文書分割や3層構造の強制はしません。既存文書内の見出しや冒頭要約だけで読者の必要を満たせる場合は、それを優先します。

## 依頼例

```text
添付したPhase要件と設計文書をもとに、部門責任者向けの1ページ程度の概要を作ってください。
現在の到達点、決める必要があること、主なリスク、次工程を先に示し、根拠となる要件・設計の見出しへリンクしてください。
概要は実装指示の代わりにせず、実装担当者が参照する詳細を残してください。
```
