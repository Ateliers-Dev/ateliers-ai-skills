# Skill の基本

作成日：2026-11-06 ／ 更新日：2026-11-06

## Skill が担うもの

Skill は、繰り返し行う作業の判断基準や手順を AI に渡すためのまとまりです。例えば文書レビューなら、何を確認するか、事実と提案をどう分けるか、対象文書を変更してよいかを記述します。

対応ツールでは名前と説明から必要な Skill を選び、使用時に本文を読み込む仕組みがあります。常に全 Skill の全文を会話に貼る運用を避けられます。読み込みや選択の詳細はツールによって異なります。[各 AI ツールでの使い方](ai-tools.md) を参照してください。

Skill を使ってもモデルの追加学習は行いません。また、Skill の記述だけで権限を付与したり、誤りを完全に防いだりするものではありません。利用するツールの権限設定と、結果の確認は引き続き必要です。

## 最小構成

このリポジトリでは、Skill ごとに次のフォルダを持ちます。

```text
skills/
  ateliers-document-review/
    SKILL.md
```

`SKILL.md` の先頭には YAML frontmatter を置き、その後に Markdown で指示を記述します。

```yaml
---
name: ateliers-document-review
description: 技術文書のレビューを依頼されたときに使う。
---
```

上の例は構造の説明用です。実際の Skill には、より具体的な説明とレビュー手順があります。

| 項目 | 役割 |
| --- | --- |
| `name` | Skill の識別名。このリポジトリではフォルダ名と一致させる |
| `description` | 何を行い、どのような依頼で使うかを示す |
| 本文 | 作業範囲、判断基準、結果の伝え方などを示す |

必要になった場合は `references/` に参考資料、`scripts/` に実行用の補助処理、`assets/` にテンプレートなどを追加できます。初版の文書レビュー Skill は `SKILL.md` だけで完結します。

基本形式は共通でも、追加の設定項目やツール連携には製品固有のものがあります。ある AI で動作したことだけで、別の AI でも同じ動作になるとは判断しません。

## このリポジトリの構成

```text
skills/   AI が使う Skill 本体
tests/    入力、実行プロンプト、期待値、検証記録
docs/     利用者向けの説明
```

`skills/` は保管・配布用です。クローンしただけで全 AI ツールに登録されるわけではありません。利用先の決められた場所に Skill フォルダを配置するか、利用先のインストール機能を使います。

名前の `ateliers-` は、このリポジトリの Skill を識別しやすくするための接頭辞です。複数の場所に同名 Skill を配置したときの扱いはツールごとに異なるため、配置の重複にも注意してください。

## Skill 本体と説明文書の違い

AI に実行してほしい指示の正本は `SKILL.md` です。`docs/` は利用者が用途や使い方を把握するための文書であり、通常は Skill のインストール先にコピーする必要はありません。

テストの入力や期待値も Skill 本体とは分けます。[文書レビューの確認方法](document-review.md) では、構造の検証と、実際の回答・行動の評価を区別しています。

参考：[OpenAI の Skill ガイド](https://learn.chatgpt.com/docs/build-skills)、[Agent Skills の形式仕様](https://agentskills.io/specification)。
