# 実行プロンプト

各IDを `inputs/cases.md` から1件ずつ渡す。実行者には対象Skill本体とそのケースだけを先に渡し、期待事項と作者回答は試行後に評価者へ渡す。ケース間の承認やツール応答を流用しない。

```text
skills/ateliers-github-issue/SKILL.md をこの合成ケースに適用してください。
入力：<N1/S1/S2/R1/B1/M1/D1/O1/P1/A1/U1/T1/H1/F1/L1の該当節を貼付>
ケースのGitHub情報は模擬応答です。実サービスへの書き込みは禁止します。
下書き・確認質問・判断・模擬的に必要な操作を返してください。
模擬操作と実操作を区別し、存在を確認していないIssueの成功を報告しないでください。
```

承認前のケースは承認待ちまでで止める。追加ターンで承認を与える場合は、承認した登録先・内容・設定を試行記録に添える。P1/T1/H1は与えられた事前承認と模擬応答を使う。N1は最初の回答に下書きがあるか、不要な質問や全履歴検索を先行していないかを記録する。
