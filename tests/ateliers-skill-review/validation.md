## 未検証・限界

- 独立チャットでの回答評価、インストールと自動選択、異なる AI 製品・モデルでの実機確認。
- GitHub Forms の画面表示・サーバー側の完全なスキーマ受理・実投稿。公式の Issue Forms 構文資料に照らしたローカル検証まで。実在 Issue は作成していない。
- 起票を明示許可した場合の実サービスでの実行。権限不足ケースは指示・報告設計の自己確認であり、接続を実際に遮断した動作試験ではない。
- 外部リンクの全件到達性、Docusaurus のビルド、実在する多数の Skill や大規模入力。
- 日付の形式検証は歴史的な作成日の証明ではない。既存の記載値を保持した。将来の更新では差分と JST 当日を別に確認する。
- チェッカーは通常の Markdown を対象とし、HTML/MDX、入れ子括弧など高度なリンク記法・製品固有アンカー規則を完全には解析しない。テストと docs の存在は確認するが、意味上の十分性は人が評価する。
- Python 実行環境が利用できず skill-creator の quick_validate.py は未実行。代わりに YAML パーサーを使う構造チェックを実行。構造合格は意味・安全性・常時の指示遵守を保証しない。
