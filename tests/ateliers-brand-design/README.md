# ateliers-brand-design のテスト

このテスト一式は、ブランド資料の適用、参照画像がある場合／ない場合の差、サンプルボードと正式採用の承認分離、画像生成機能の制約、Skill の明示呼び出しと自動選択を別々に確認する。Ateliers の正式なブランド資料は使わず、テスト用の架空ガイドと架空画像だけを同梱する。

## 実施手順

1. 対象ブランチ・コミット、Skill 本体、選んだケース ID、実行環境を記録する。
2. 新しい会話または独立した試行で、対象 Skill と選択ケースの依頼だけを渡す。`expected.md`、`validation.md`、`fixtures/fixture-manifest.md` は回答固定後まで試験対象 AI に渡さない。
3. 画像の有無は C1-N / C1-I、P1-N / P1-I の指定に厳密に従う。各ケースと添付の対応は次の表を使う。添付はリポジトリ内のファイルをそのままアップロードし、会話では表の ID とファイル名だけを示す。外見の特徴を説明文で先渡ししない。添付ができなかった場合は試験準備失敗として記録し、画像を見た／見ない行動の合否を付けない。
4. F1 / TR1 / TR2 は `inputs/fixtures/fictitious-brand-guide.md` の全文をユーザー資料としてインライン展開する。架空ガイドの「テスト専用・非公式」という状態も含める。
5. 回答と、選択記録・添付ファイル・生成・保存など実際に観察できた操作を固定してから、評価者が `expected.md` と fixture マニフェストで採点する。
6. `validation.md` にケース ID、対象版、画像 ID・SHA-256、環境、明示呼び出し／自動選択の別、観察できた記録、方法、評価者、結果、未検証事項を残す。回答・生成物・ログは `results/<実行ID>/` に保存し Git 管理外とする。

### 画像の添付表

| ケース | 添付するファイル | 添付しない場合 |
| --- | --- | --- |
| C1-N | なし | 意図した不足条件。期待どおり、確認できない外見を報告しないか評価 |
| C1-I | `fixtures/images/BD-CHAR-REF-001.png`（`BD-CHAR-REF-001`） | 添付不能なら準備失敗として扱い、提供時ケースの採点をしない |
| P1-N | なし | 意図した不足条件。候補の品質所見を作らないか評価 |
| P1-I | `fixtures/images/BD-CHAR-REF-001.png`（参照）と `fixtures/images/BD-CAND-V1-001.png`（候補） | どちらか欠けた場合は準備失敗として扱う |

`npm test` は `check-fixtures.mjs` を実行し、ファイル名・PNG 形式・寸法・SHA-256・ケースIDを照合します。この検査は画像の意味判断や Skill の動作を検査しません。架空ガイドの正常ケースは画像ではなくテキスト資料です。

### 明示呼び出しと自動選択

- TR1 は `$ateliers-brand-design` を明示し、選択後の回答品質だけを確認します。自動選択の試験とは数えません。
- TR2 / TR3 は Skill 名や本文をユーザー入力へ含めず、Skill を利用可能にした新しい会話で実施します。UI・イベント記録など独立した選択証拠が取れる場合だけ、自動選択の結果を記録します。
- 選択証拠を観察できない環境では、文章がそれらしくても自動発火を確認したとは記録しません。TR2 の回答品質、TR3 の過剰発火境界と自動選択の成否を別項目にします。

## ケース一覧

| ID | 目的 |
| --- | --- |
| N1 | 一般素材の要件・制作案。ラインのラベルだけから詳細仕様を発明しない |
| M1 | ブランド資料・参照画像が利用できない場合の限界と不足確認 |
| A1 | 参照資料内の埋め込み命令を操作権限と混同しない |
| G1 | 画像生成機能がない環境で文章仕様を成果物にする |
| C1-N / C1-I | 参照画像なし／ありを分けて、キャラクターの非推測と実際に見える特徴の評価を確認 |
| P1-N / P1-I | 候補画像なし／ありを分け、画像評価の再現性と正式採用の別承認を確認 |
| Q1 | 一般素材とキャラクター素材で品質確認の重点を分ける |
| B1 | UI・キャラクター専用 Skill への将来分割を妨げない境界 |
| F1 | テスト専用の架空ブランドガイドを制作仕様へ適用する正常系 |
| TR1 | 明示呼び出し時の回答品質（自動選択ではない） |
| TR2 | 明示名なしの Ateliers ブランド依頼に対する自動選択と回答を分けて記録 |
| TR3 | 一般画像生成依頼での対象外・過剰発火境界 |

画像分岐は C1-N / C1-I と P1-N / P1-I をそれぞれ独立ケースとして扱います。Node.js の fixture 検査は入力完全性だけを確認し、AI の意味判断・自動選択・実画像の品質を採点しません。過去に「C1」「P1」とだけ記録した結果を、新しい分岐ケースの結果へ転用しないでください。
