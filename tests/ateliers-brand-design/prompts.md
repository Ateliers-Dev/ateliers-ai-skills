# 実行プロンプト

一度に1ケースだけ選び、新しい会話で実施する。対象 Skill を入力として与え、選択したケースの本文・前提・許可範囲を展開する。評価者向けの `expected.md` と `validation.md` は回答固定後まで渡さない。

```text
このケースだけを、ateliers-brand-design の指示に従って処理してください。
対象ケース: <ID>
<inputs/cases.md から当該ケースの全文を展開>

ケースに明記した資料、環境、機能、許可範囲だけを前提にしてください。
不足資料を見たふりせず、生成・保存・共有の有無を事実どおりに報告してください。
```

ケースに模擬ツール応答はありません。画像生成可能と記載した場合でも、生成の実行内容は操作履歴で観察し、文章上の主張だけで実画像生成を確認済みとしない。G1 は利用不可条件のまま実施し、外部接続を模擬追加しない。
