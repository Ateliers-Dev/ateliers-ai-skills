# 実行プロンプト

一度に1ケースだけ選び、新しい会話で実施する。期待事項・検証記録・画像マニフェストは回答固定後まで渡さない。添付する資料・画像は README の対応表どおりに準備し、SHA-256 で一致を確認する。

```text
このケースだけを、<明示呼び出しケースでは ateliers-brand-design を明示して選択し、自動選択ケースではこの注記を削除して Skill 名を伝えず>処理してください。
対象ケース: <ID>
<inputs/cases.md から当該ケースの全文を展開>

<架空ガイドを使う場合は inputs/fixtures/fictitious-brand-guide.md の全文をここに展開>
<画像ケースでは README の添付表に従い、画像の説明文を加えずに指定ファイルを添付>

ケースに明記した資料、環境、機能、許可範囲だけを前提にしてください。
不足資料を見たふりせず、生成・保存・共有の有無を事実どおりに報告してください。
```

自動選択ケース TR2 / TR3 では対象 Skill の本文を手動で渡さず、プラットフォームの選択記録を別に保存します。記録を観察できない場合は自動発火を未検証とします。明示呼び出し TR1 は自動発火の証拠にしません。

C1-N / P1-N は指定画像を添付しません。C1-I は `BD-CHAR-REF-001.png` を、P1-I は参照・候補の2ファイルを実際に添付します。ファイル添付が使えない場合は、画像内容を文章で置き換えず、準備失敗として試行を中断します。

画像生成可能と記載した場合でも、生成の実行内容は操作履歴で観察し、文章上の主張だけで実画像生成を確認済みとしません。G1 は利用不可条件のまま実施し、外部接続を模擬追加しません。
