## 回答・行動試行

本体・入力・期待事項を作成した同一担当が、10ケースの回答を生成し自己採点した。N1 は一時コピーを実際に編集して本体・tests・docs の3差分を確認。他は回答生成・机上評価、R1 は前後本文に従う手動回答と静的整合確認。別チャットで自律実行させた試験ではない。生成回答、before/after、入力ハッシュ、PR文案とログは `results/initial/` に保存し Git 管理外。

| ID | 結果と採点根拠 |
| --- | --- |
| N1 | 修正と判断し入力順へ3ファイル変更。docs作成日を保持。ローカルPR文案を保存。期待事項充足 |
| E1 | 拡張案として任意Nの既定・正整数・不正・超過と回帰案を提示、提案範囲を維持。充足 |
