# 試行プロンプト

各 ID ごとに新しい一時作業コピーを作り、次の依頼に inputs/cases.md の該当節を添える。R1 は N1 の作成物を使う。

```text
skills/ateliers-skill-improve/SKILL.md を使い、この依頼に対応してください。
対象は一時コピーの sample です。関連 Skill・standards・Catalog は読み取りで参照できます。
ケースが許可した範囲だけ編集してください。実リポジトリ、main、外部サービスは変更しないでください。
判断根拠、変更前後、影響、検証、未検証、切り戻し、引き継ぎを報告してください。
```

独立試験では expected.md、過去の回答、作者の結論は先に渡さない。許可のある自己試行でも独立試験とは区別する。
