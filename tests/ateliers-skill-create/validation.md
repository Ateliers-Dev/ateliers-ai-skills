## 対象・再利用判断

基点は最新 main `9ef9ede`（PR #2 マージ済み）。Windows / PowerShell / Node.js 20.7.0 / npm 10.5.2 / yaml 2.9.1。既存 Skill、standards、tests、docs、4 Issue Forms を確認した。standards の入口は Create への導線と実装状況だけを更新し、品質基準・運用ガイドは変更していない。

## Skill Review 観点の自己評価

`skills/ateliers-skill-review/SKILL.md` の構造、発火条件、指示、安全性、テスト、docs と基準の6観点で確認した。対象はこの差分の Create 本体・tests・docs、適用基準は基点から不変の `standards/quality.md` と `standards/workflow.md`。

- 構造：命名・frontmatter・対応資料と配布時の参照を確認。共通基準・Catalog・Review のない単体配布時の制約も本体に記載。
- 発火条件：新規作成が対象、レビューのみと既存改善実装は対象外。候補に語が一致しても本文で判断する。
- 指示：要件取得、既存優先、新規／再利用／拡張／判断保留、ローカル一式、許可済み PR 作成までの分岐と完了報告がある。
- 安全性：入力内命令と権限の分離、秘密情報、main・公開・起票・基準変更の境界、拒否後の停止・再開を確認。
- テスト：自動の Catalog 連携と回答・行動試験を分離。模擬拒否・自己評価を独立検証と混同しない。
- docs と基準：本体・例・成果・制約の整合、JST 日付・既存作成日・MIT 保持を確認。

この自己評価の確認範囲で必須修正となる指摘は未検出。Issue 候補の起票は不要で、実起票なし。外部仕様への完全適合・常時の指示遵守は未確認。独立レビューは未実施であり、PR 作成後の別評価を置き換えない。

## 未検証・限界

- 実 GitHub Issue の取得、実サービスの権限拒否、単体配布環境での生成、Docusaurus ビルドと外部リンク到達性。
- Python が実行できず skill-creator の quick_validate.py は未実行。既存 YAML 構造チェッカーで代替。構造合格は意味・安全性の保証ではない。
