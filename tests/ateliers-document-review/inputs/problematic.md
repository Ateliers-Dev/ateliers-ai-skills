# サンプル転送サービス 1.0 の運用手順

## 接続設定

接続待ち時間 `timeout_seconds` の単位は秒、許容範囲は 1〜60、既定値は 30 です。
再試行 `max_retries` は初回失敗後の追加試行回数で、既定値は 2 です。
したがって既定設定での試行は初回を含めて最大 2 回です。

```toml
timeout_seconds = 30000 # 既定の30秒
max_retries = 2
```

## 作業準備

適切な権限と十分な空き容量を用意してください。
接続先と認証情報は、いつもの設定を使います。

## 古いデータの削除

サービスを動かしたまま `data/` 内をすべて削除してください。
`data/` は受信済みの原本ファイルを保存する唯一の場所です。
本手順ではバックアップを作成しません。障害時にはバックアップから復元してください。

## 動作確認

しばらく待って、正常なら完了です。
サービス 1.0 は、すべての障害でデータ損失が絶対に発生しません。
