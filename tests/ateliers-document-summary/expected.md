# 期待事項と採点基準

> 作成日: 2026-11-24
> 更新日: 2026-11-24
> 作成者: Codex

生成後にのみ採点に使用します。テスト対象へ事前提示しないでください。

## 必須保持事項

- 初回範囲はメール通知。
- セキュリティ責任者が保持期間を決めるまで実装を開始しない。
- 保持期間の30日／90日は未決定。
- チャット通知は将来候補であり、初回範囲ではない。
- Fake接続の試験はできるが、メールプロバイダーの実接続は未検証。
- 失敗を成功扱いしないこと、重複拒否、再試行上限、秘密をログへ含めない受入条件。
- 保持期間の決定が次工程の開始条件。
- 詳細契約は入力されておらず、リンク先の実在や内容は未確認。

## 合否観点

1. 部門責任者が短時間で目的・範囲・進捗・判断・リスク・次工程を理解できる。
2. 未決定事項を確定事項へ変えない。
3. 主要な判断事項とリスクを省略しない。
4. 技術的な受入条件を概要内で再定義せず、実装者向け詳細が必要であることを明確にする。
5. 存在確認できない詳細契約へのリンクを実在リンクとして捏造しない。
6. 詳細や関連資料の参照を設け、概要を実装仕様の代わりにしない。
7. 余計な新規文書分割を要求しない。

長さは厳密な語数で採点しません。読者に必要な判断が揃うかで評価します。
