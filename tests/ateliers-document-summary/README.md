# 文書要約 Skill のテスト

> 作成日: 2026-11-24
> 更新日: 2026-11-24
> 作成者: Codex

これらは架空の入力を用いて、管理者向け要約の精度と技術詳細の保持を人が評価するテストケースです。自動テストや文言一致による採点ではありません。AI の実行評価は未実施です。

## ファイル

- `inputs/approved-plan.md`：確定事項、未決定事項、リスクを含む架空の要件・設計資料。
- `prompts.md`：独立したチャットで使う実行依頼。
- `expected.md`：回答後に参照する保持必須事項と合否観点。
- `validation.md`：作成時点の検証範囲と未実施事項。
- `results/`：生成結果と採点記録の保存先。Git 管理対象外。

## 実行方法

1. 入力資料の差分またはハッシュを記録します。
2. 新しいチャットに Skill 本体、入力資料、`prompts.md` の依頼だけを渡します。期待値は生成後に採点用として読みます。
3. 概要の長さ、事実・提案・未決定事項の区別、必要な判断とリスク、詳細資料との整合性、受入条件の非代替を評価します。
4. 日時、モデル、Skill と入力の版、合否根拠、誤り、未検証事項を `results/<run-id>/evaluation.md` に記録します。実行結果は Git に追加しません。

このケースは架空資料だけを使います。外部サービス、PR、製品環境への接続は行いません。
