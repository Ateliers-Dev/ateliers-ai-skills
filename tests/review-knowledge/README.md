## P2 修正の要求・安全方針

PR #12 の独立レビュー P2 を修正します。対象版 `e593f55` では生成・照合がジャンクションを追跡するため、正本・出力・相対リンクの対象と既存親を副作用前に検査する方針へ変更します。変更箇所は生成器、対応テスト、この手順と検証記録だけです。

許可領域はリポジトリ内です。ファイルシステムのルートから既存の各親と対象を `lstatSync` で調べ、シンボリックリンクと Windows ジャンクションを拒否します。内向きリンクや、リポジトリ自体・その親をリンク経由で指定する配置も拒否します。`realpathSync.native` と各パスの一致も確認し、実体の異なる経路を拒否します。通常のファイルと親ディレクトリだけを受け付けます。

正本と相対リンク先は存在必須です。生成先が存在しない場合は最後の既存親まで検査し、全入力・全出力の検証後にだけ生成します。照合では一切作成しません。生成直前とディレクトリ作成後にも出力経路を再検査します。

これはパス検査であり、検査と I/O の間に別プロセスが行う置換（TOCTOU）を完全には防ぎません。実行中に第三者が経路を変更しない作業領域を前提とします。Windows の全 reparse tag を列挙する実装ではなく、Node.js がリンクとして報告せず実体パスも変わらない特殊な reparse point、ハードリンクの別名は保証対象外です。全種類の reparse point を拒否したとは主張しません。[Node.js のファイルシステム API](https://nodejs.org/api/fs.html)に基づく検査です。

回帰テストは Windows でジャンクション・ディレクトリシンボリックリンク・ファイルシンボリックリンクを分けて実行します。リンク作成時の `EPERM` / `EACCES` / `ENOSYS` / `ENOTSUP` だけを種類・理由付きで skip とし、作成後の検証失敗は失敗として扱います。外向き/内向き、root/その親、壊れたリンク、未作成の出力階層、ファイルリンクを拒否し、外部の目印と参照対象の内容・ナノ秒単位の mtime、既存生成物の保持を確認します。

## 再実行

### 2件目のP2: CLIのリンク経由起動

対象版 `ccca394a36697b0a7472bd11ac32956a51b5d43a` のCLI判定は、ESMが実体へ解決したパスと起動引数の文字列を比較していたため、rootのジャンクション経由では同期も引数検査も実行せず終了0になりました。修正後は両者の実体パスを `path.relative` で比較して直接起動を判定し、起動引数側の経路を既存の共通検査で拒否します。通常のESM import、argvなし・非実在の `-e` importではCLIを実行しません。

CLI subprocessで欠落・正本更新後の未同期を分け、実体経由の既定/--checkは終了1・診断あり・副作用なし、--writeは生成成功、その後の照合成功を確認します。rootリンク経由は既定/--check/--write/未知引数を終了1・リンク拒否の診断あり・標準出力なしにします。絶対指定、aliasをcwdにした相対指定、--preserve-symlinks-mainを確認し、全ファイルの内容・mtimeとディレクトリ一覧を保持します。Windowsの大小文字・区切り表現も検証します。リンク作成不可は上記と同じ理由付きskipとし、通常成功と区別します。

変更範囲は生成器・CLI回帰試験・本手順・検証記録です。この修正だけを戻す場合は `ccca394` の後の今回のコミットをrevertし、check/testを再実行します（CLIのすり抜けが再導入されます）。TOCTOU・特殊reparse point・ハードリンクの制約は前述のままです。

Node.js 18以上で `npm ci` の後、リポジトリルートから実行します。

```text
npm run knowledge:generate
npm run check
npm test
git diff --check
```

照合だけなら `node scripts/sync-review-knowledge.mjs` または `--check`、個別の自動テストは `node --test tests/review-knowledge/sync.test.mjs` です。明示生成は Git 管理の生成物を書き換えます。テストは OS の一時領域を使い終了時に削除し、リポジトリの正本と生成物は変更しません。

実インストーラーの試験は Windows で実行します。ユーザーの実際のインストール先へは配置せず、一時リポジトリと一時コピー先を使います。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/tools/Install-Skills.Tests.ps1
pwsh -NoProfile -File tests/tools/Install-Skills.Tests.ps1
```

[検証記録](validation.md)で作者実行・未検証事項を区別します。ログ等の生成結果を保存する場合は `tests/review-knowledge/results/` を使い、Git 管理しません。

切り戻す場合は PR A の変更一式を戻し、check/test を再実行します。Skill 本体・インストーラー本体・standards の変更や main の書き換えは不要です。

P2 修正だけを戻す場合は `e593f55` の後に追加した修正コミットを revert し、check/test を再実行します。ただし元のリンク追跡の欠陥も再導入されるため、その状態での生成は避けてください。
