# テスト文書

> 作成日: 2026-11-19
> 更新日: 2026-11-19
> 作成者: Codex

テスト資産は、Skill や機能ごとに `tests/<suite>/` へまとめます。各スイートの README に実行方法とファイルの役割を記載し、検証記録や E2E 記録も対象スイート内で管理します。

入力、期待値、プロンプト、fixture はテスト仕様の一部です。これらを移動・変更する場合は、テストコード、生成器、参照先も確認してください。実行結果は各スイートの `results/` に保存し、Git 管理には含めません。

新しいテスト文書の種類や配置を追加・変更した場合は、この README と該当スイートの README を更新してください。

- [ateliers-document-summary](ateliers-document-summary/README.md)：管理者向け概要の要約精度、判断・リスクの保持、詳細資料との整合性を評価します。
